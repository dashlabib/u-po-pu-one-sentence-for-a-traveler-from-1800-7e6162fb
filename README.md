One sentence of 153 characters explaining the modern internet to a time traveler from 1800, built only from things they already know: a post office, a library, a market, a road, a letter. The program validates the sentence against the bounty gate and publishes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
